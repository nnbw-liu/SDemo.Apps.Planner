# 事序（sdemo.planner）需求计划

> 状态：v4 需求（2026-11-06）。产品显示名「事序」，副标题「项目与日常」；v1 的「待办 + 日历」保留为底层能力，产品中心是「项目推进 + 日常节奏」。
> 关联：[v4 设计](planner-v4.md) · [v3 设计](planner-v3.md) · [v2 设计](planner-v2.md) · [v1 设计](planner-design.md) · [MCP 工具面](planner-mcp-surface.md) · [P2 验收](p2-verification.md) · [联动需求](../../../docs/integration.md)

## 1. 目标与边界

**一句话**：用项目承接目标，用迭代拆节奏，用任务推进，用日常守住生活。

- 一个本地应用、一个 SQLite 库；项目、迭代、工作项、日程、日常各自建表，不做一个万能实体。
- 工作项复用 `todo`：可完成、可设截止时间，支持 `task / bug / research / chore` 四种类型。
- 日程 `event` 与工作项同库不同表：有起止、地点、参与人。
- 日常 `routine` 与打卡 `routine_check` 独立：喝水、吃药、起身走动等重复事项。
- **零模型凭证**：AI 草稿由 DesktopAgent 生成，本应用只校验、去重提示、入库。
- 数据目录：`%APPDATA%\SDemo\Apps\sdemo.planner\`（`planner.db` + `outbox\`）。

**明确不做**：团队共享、多人 ACL、完整 RRULE 编辑、双向日历同步、云同步、模型调用。

## 3. 非功能与数据

| 项 | 约定 |
| --- | --- |
| UI | WPF 外壳 + `BlazorWebView`；业务 UI 在 `SDemo.App.Planner.Web` |
| 存储 | SQLite；`project` / `iteration` / `routine` / `routine_check` / `todo` / `event` / `list` / `tag` / `links` / `draft` / `outbox` |
| 时间 | 一律存 UTC，按本地时区显示；日常打卡按本地 `yyyy-MM-dd` |
| 迁移 | 真实 EF migrations（不用 `EnsureCreated`）；启动时单实例迁移 |
| 搜索 | FTS5 + 2-gram 预分词；中文两字可命中 |
| 提醒 | 进程内 30 秒 tick；非激活 Toast；关闭窗口收进托盘，进程与提醒继续 |
| 状态 | `todo.status` 六值；终态 `done/verified/closed/canceled`；完成说明/产物独立列 |
| 托盘 | Win32 `Shell_NotifyIcon` + WPF ContextMenu；不引入 WinForms |
| 组件 | 只读 + 勾选 + 快速新增；不渲染完整日历 |
| 审阅 | 草稿区与正式表物理分开；采纳才写 `source` / `sessionId` / `quote` |

## 4. 工程约束（多仓）

- 六件套：`SDemo.App.Planner.{Contracts,Storage,Core,Mcp,Web,Host}`；`Mcp` 单独工程，工具面与领域逻辑物理隔离。
- Host 必须是 `Microsoft.NET.Sdk.Razor`，静态资源在 `Host/wwwroot`。
- 不引用 Agent、不引用其它 App；跨应用只存 URI 字符串（`sdemo.kb/doc/<id>@v#b`）。
- MCP 端点只回环 + 进程级 token；工具声明风险等级（低/中/高）。
- 契约（组件字段、URI、审批）以主仓 [contracts](../../../docs/contracts/) 为准。

## 6. 联动点

| 联动 | 做法 |
| --- | --- |
| 会议候选 → 工作项 | Meeting 产出 `mtg_action(candidate)` → Agent 调 `todo_create_draft` → 用户审阅 |
| 工作项关联文档 | 存 `sdemo.kb/doc/<id>@v#b` 字符串；Agent 解析跳转 |
| 统一搜索 | Agent fan-out 调 `todo_search` / `calendar_range`，结果合并排序 |
| 高风险审批 | 删除 / 批量≥5 / 清空 → 每次确认 + 审计，不可关闭 |
| 桌面组件 | 复用 `Web/Widgets/PlannerWidget.razor` 的参数与事件 |

## 7. 风险与待定

| 项 | 说明 |
| --- | --- |
| R1 | 项目/迭代/任务层级容易膨胀 → 迭代固定两层，任务只允许一层子任务 |
| R2 | 提醒常驻进程与退出语义 → 关闭收进托盘，退出走托盘/侧栏显式按钮；托盘使用 Win32 隔离实现 |
| R3 | Blazor 日期/时间输入格式不稳 → 统一走 `DateValue/TimeValue` 规范化 |
| Q1 | 项目归档后是否仍显示在首页 → 当前只显示 active/paused，归档隐藏 |
| Q2 | 间隔提醒的跨天行为 → 当前按当天时间窗，不跨天补发 |
| Q3 | 回收站是否覆盖项目/迭代 → 当前项目/迭代软删但不在回收站列表，任务/日程可恢复 |
